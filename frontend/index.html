Versiones del modelo

Enviar archivo de entrenamiento

CSV con las 18 columnas del dataset (nombres originales en inglés o en español). El servicio lo valida, limpia (tipos, nulos, duplicados) y lo guarda en la base de datos. POST /training-data

Reentrenar el modelo

Entrena una nueva versión con todos los datos de la base de datos, usando el algoritmo e hiperparámetros elegidos en el notebook. Se activa solo si cumple Recall ≥ 70 %. POST /retrain
